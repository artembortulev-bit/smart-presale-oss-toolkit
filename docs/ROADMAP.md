# Roadmap

## Current Status

Smart Presale OSS Toolkit is an early open-source reference implementation with working vertical slices:

- client intake;
- deterministic recommendation logic;
- cost benchmark foundation;
- proposal draft and PDF generation;
- proposal/versioning direction;
- manager workspace direction;
- demo-readiness scripts;
- limited 3D visual proof layer.

It is not yet a finished production SaaS product.

## Near-Term Priorities

1. Transactional persistence for the operational core.
2. Real auth, users, roles, and ownership.
3. Manager workspace hardening.
4. Proposal lifecycle and versioning.
5. Client-to-sales handoff.
6. Qualification layer.
7. Event analytics MVP.
8. Demo-safe dataset and asset packaging.

## Intentionally Out Of Scope For Now

- Full CRM integrations.
- AI/RAG/vector search.
- Large-scale 3D asset pipeline.
- Broad visual redesign.
- Production customer data import.
- Production asset hosting.
- Full SaaS billing or tenant management.

## Future Directions

- Better 3D asset pipeline with explicit demo/prod boundaries.
- Integration examples for CRM or ERP systems.
- Optional AI-assist after the operational core is stable.
- CRM adapters later.
- More test fixtures for proposal versioning and sales actions.
- Release automation and public demo environment.
